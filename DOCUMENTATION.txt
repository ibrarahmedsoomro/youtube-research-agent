1. PROJECT OVERVIEW
--------------------------------------------------------------------------------
Yeh project ek autonomous AI-powered YouTube Research Agent hai jo VidIQ aur 
TubeBuddy jese tools ke core features ko replicate karta hai.

Is agent ka maqsad creators aur researchers ko:
- High-demand, low-competition keywords dhoond kar dena.
- Competitors ke viral outliers (jo videos channel average se 5x-10x zyada 
  views le rahi hain) identify karna.
- View Velocity (VPH - Views Per Hour) calculate karna taake live trends 
  ka pata chal sake.
- AI ke zariye high-CTR titles, SEO descriptions, tags, thumbnail concepts 
  aur complete video outlines generate karna.

Khas Baat:
Yeh poora system YouTube Data API ke baghair (100% Free & Unlimited) kaam 
karega via high-performance scraping aur extraction techniques.

3. MODULE-BY-MODULE BREAKDOWN
--------------------------------------------------------------------------------

MODULE 1: DATA EXTRACTION & INGESTION (Free Scraping Engine)
------------------------------------------------------------
Files to build:
- scraper/video_scraper.py      : Single video ya keyword search scraper.
- scraper/channel_scraper.py    : Channel ke historical aur recent videos.
- scraper/transcript_scraper.py : Video ka spoken script/subtitles fetch karna.
- scraper/models.py             : Clean data models (dataclasses / Pydantic).

Features:
- Bina Google API key ke chalega.
- Daily 10,000 units quota ki koi restriction nahi.
- Auto-retries aur lightweight caching taake YouTube block na kare.


MODULE 2: VIDIQ METRICS & ANALYTICS ENGINE
------------------------------------------
Files to build:
- analytics/velocity.py        : Views Per Hour (VPH) & momentum calculations.
- analytics/outlier.py         : Outlier Score (e.g. 3.5x means 350% more views
                                than channel's average).
- analytics/seo_scorer.py      : Keyword density, tag relevance, title length score.

Core Formulae:
1. Video Age in Hours = (Current Time - Upload Time) in hours.
2. VPH (Views Per Hour) = Total Views / Video Age in Hours.
3. Channel Median Views = Median(all recent 30 videos of that channel).
4. Outlier Score = Video Views / Channel Median Views.
   - Outlier Score > 2.0 = Performing well
   - Outlier Score > 5.0 = Breakout Viral Video (Huge Opportunity!)
5. Engagement Score = ((Likes * 1.5) + (Comments * 3.0)) / Views * 100.


MODULE 3: AI RESEARCH & SEO INTELLIGENCE CORE
---------------------------------------------
Files to build:
- ai/prompts.py                : VidIQ-style structured prompt templates.
- ai/title_generator.py        : 10 viral title variations categorized by type
                                (Fear, Curiosity, Listicle, Authority).
- ai/content_gap.py            : Transcripts aur competitor comments analyze
                                karke gaps dhoondna.
- ai/seo_generator.py          : High ranking tags, optimized descriptions.
- ai/thumbnail_agent.py        : Thumbnail concepts (visual layout, text on
                                thumbnail, emotion, color contrast).


MODULE 4: COMPETITOR TRACKER & NICHE SPY
----------------------------------------
Files to build:
- competitors/tracker.py       : Multiple channels ko compare karna.
- competitors/benchmark.py     : Competitors ke top performing themes filter karna.


MODULE 5: INTERACTIVE DASHBOARD & CLI
-------------------------------------
Files to build:
- app.py                       : Streamlit web application.
- cli.py                       : Command line runner for quick terminal usage.
